# Nijuni ZMK config

Конфигурация для 42-клавишной, 6-колоночной Nijuni (совместима с Corne): две
половины на `nice!nano v2`. Раскладка находится в `config/corne.keymap`.

## Изменить и собрать прошивку

1. Отредактируйте `config/corne.keymap`. В ZMK порядок привязок для Corne:
   три ряда слева направо через обе половины, затем три левые и три правые
   thumb-клавиши.
2. Проверьте изменения и отправьте их в GitHub:

   ```sh
   cd /path/to/nijuni-zmk-config
   git diff
   git add config/corne.keymap
   git commit -m "Describe the keymap change"
   git push origin main
   ```

3. GitHub Actions автоматически соберёт `corne_left` и `corne_right`. Откройте
   вкладку Actions репозитория и дождитесь статуса `success`.

## Скачать UF2 через Terminal

Замените `RUN_ID` идентификатором успешного запуска Actions. Последний запуск
можно увидеть так:

```sh
cd /path/to/nijuni-zmk-config
gh run list --branch main --limit 3
```

Скачайте артефакт в отдельную папку:

```sh
mkdir -p firmware/RUN_ID
gh run download RUN_ID --name firmware --dir firmware/RUN_ID
ls -lh firmware/RUN_ID/*.uf2
```

В результате должны быть два разных файла:

- `corne_left-nice_nano__zmk-zmk.uf2` — только для левой половины;
- `corne_right-nice_nano__zmk-zmk.uf2` — только для правой половины.

Папка `firmware/` — локальный кэш артефактов и не коммитится в Git.

## Прошить через Terminal

Новая прошивка заменяет установленную. При первой установке этой конфигурации
прошивайте обе половины; при дальнейшем изменении только keymap обычно
достаточно прошить левую, центральную половину.

1. Подключите нужную половину USB-кабелем с передачей данных.
2. Дважды быстро нажмите её кнопку Reset. В Finder появится накопитель
   `NICENANO`.
3. Скопируйте соответствующий файл в корень накопителя. Для левой половины:

   ```sh
   cp -X firmware/RUN_ID/corne_left-nice_nano__zmk-zmk.uf2 /Volumes/NICENANO/
   ```

   Для правой половины сначала переведите в bootloader именно её, затем:

   ```sh
   cp -X firmware/RUN_ID/corne_right-nice_nano__zmk-zmk.uf2 /Volumes/NICENANO/
   ```

`-X` не передаёт служебные метаданные macOS, которые Finder пытается записать
на UF2-накопитель и из-за которых может показать ошибку `-36`.

После записи `NICENANO` сам исчезает: контроллер перезагружается в новую
прошивку. `cp` при этом иногда выводит `Input/output error` или `Device not
configured` на завершающем шаге (`fchmod`). Если накопитель исчез после команды,
это нормальный признак успешной записи — не копируйте UF2 повторно. Если
`NICENANO` остаётся подключённым и клавиатура не перезагружается, запись не
удалась: попробуйте другой USB-кабель или порт.

После прошивки обеих половин включите их и подождите несколько секунд: split
соединение устанавливается автоматически. Если половины не соединяются, не
сбрасывайте настройки сразу: сначала зафиксируйте наблюдаемое поведение.
